## Environment and provenance

C5 ran in the machine-native `/workspace/0z5a` environment with Python 3.12.14, PyTorch 2.13.0+cu129, vLLM 0.29.0, Transformers 5.17.0 and verl commit `7aed6b230776f963fa09509c10d9c3a767d1102c`. The tested source commit was `cf297c4a1ce806c2bc6114483fc63b86ef24e589`.

The isolated dependency overlay supplies an idempotent EAGLE model-name prefix guard, a dense-model import alias and the pinned pure-PyTorch padding helpers. Production source was unchanged. Both successful C5 runs emitted a DataLoader worker termination traceback during shutdown after 20/20; their publication barriers completed and both wrappers exited 0.

C5 confirms the lifecycle defect already present in the parent source: target synchronization restores the checkpoint drafter instead of retaining the latest trained drafter. Publication interval 1 reloads a new trained drafter after every sync, allowing the runs to finish without fixing retention.
